WEIGHT PROGRESSION LOGIC USING RPE/RIR TABLE

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHAT IS THE TABLE?
The table gives you a percentage of 1RM (one rep max) for every
combination of Reps Performed and RIR (Reps In Reserve).
This percentage is the core of all calculations.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1 — ESTIMATE 1RM FROM LAST SESSION
Using the weight the user lifted, their reps, and their RIR,
find the matching percentage in the table.

Formula:
1RM = Weight Used ÷ Table Percentage

Example: 40kg, 12 reps, 3 RIR → Table % = 70.70%
1RM = 40 ÷ 0.7070 = ~56.6 kg

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2 —  OPTION TO PROGRESS

Option A: Same reps, reduce RIR by 1 (more effort, same volume)
Option B: Same weight, add 1 rep (more volume, same effort)

Both options increase the challenge and support hypertrophy progress.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3 — CALCULATE TARGET WEIGHT (Option A example)
Find the table percentage for the same reps but 1 RIR less.

Formula:
Target Weight = 1RM × New Table Percentage

Example: 12 reps, 2 RIR → Table % = 72.48%
Target Weight = 56.6 × 0.7248 = ~41 kg

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4 — WHAT IF USER CANNOT FIND THAT EXACT WEIGHT?
This is the creative solution.

If the user picks a different available weight, use this logic:

1. Calculate what % of 1RM that available weight represents:
   Actual % = Available Weight ÷ 1RM

2. Go to the target RIR row in the table (example: 2 RIR row)

3. Scan across the reps columns and find the percentage
   closest to the Actual % you just calculated

4. That rep number is what you recommend to the user

Example:
- 1RM = 56.6 kg, user picks 42.5 kg
- Actual % = 42.5 ÷ 56.6 = 75.09%
- Scan 2 RIR row → closest match is at 10 reps (75.22%)
- Tell user: Do 10 reps at 42.5 kg with 2 RIR

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FULL ALGORITHM (IN ORDER)

1. Collect from last session: weight, reps, RIR
2. Look up table percentage for that reps + RIR combination
3. Calculate 1RM = weight ÷ table percentage
4. Calculate ideal target weight = 1RM × new table percentage
5. If user has that weight → done, give reps + new RIR
6. If user picks a different weight:
   a. Calculate actual % = that weight ÷ 1RM
   b. Scan the target RIR row in the table
   c. Find the closest matching percentage
   d. The column where it matches = recommended reps
7. Give user: weight they selected + recommended reps + target RIR

WHY THIS WORKS
Every calculation goes through the 1RM as a common reference point.
This means it does not matter what weight the user picks or what
equipment is available. The table always gives you the correct reps
to keep the user at the right level of effort and continue
progressive overload for hypertrophy.
